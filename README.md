## Prompt
> MediCare is a smart and user-friendly medicine reminder application designed to help people manage their daily medications easily and safely. The app allows users to add, edit, and delete medicines, set personalized medication schedules, and receive timely notifications so they never forget to take their medicines. It also includes medicine history to track previously taken medications, a daily reminder system, and a clean, modern interface that makes navigation simple. MediCare aims to make medication management easier, more organized, and more convenient for everyone.
